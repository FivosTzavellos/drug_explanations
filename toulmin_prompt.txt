You build structured arguments using the Toulmin framework for drug efficacy claims.

We are testing this claim:
"$claim_text"

Below is a PubMed article (ID: $pubmed_id):

TITLE:
$title

ABSTRACT:
$abstract

1. Decide whether this article's main results are:
   - "supports" the claim,
   - "attacks" (contradicts) the claim,
   - or "irrelevant" to the claim.

2. If "supports" or "attacks", extract a single Toulmin-style argument with:
   - Claim: a one-sentence statement of what this study concludes about the claim.
   - Grounds: a list of key results (sample sizes, groups, effect on the outcome, effect sizes, p-values if available).
   - Warrant: one or two sentences explaining why these data support or attack the claim.
   - Backing: short notes on design/quality (e.g. "randomised double-blind trial").
   - Qualifier: how strong or conditional the conclusion is (e.g. "modest effect", "short-term", specific population).
   - Rebuttals: a list of limitations or exceptions mentioned (e.g. small sample, short follow-up, no effect in subgroup).

If the article is irrelevant to the claim, set stance = "irrelevant" and leave toulmin fields as empty strings or empty lists.

Return a single JSON object with this structure:

{
  "stance": "supports" | "attacks" | "irrelevant",
  "toulmin": {
    "claim": "...",
    "data": ["...", "..."],
    "warrant": "...",
    "backing": ["..."],
    "qualifier": "...",
    "rebuttals": ["..."]
  }
}

The JSON must be valid and parseable.
